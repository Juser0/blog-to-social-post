# LangChain 변형 (예정)

LangChain 기반 Blog → Social 변환 구현 자리.

- 상태: 미구현 (폴더만 생성됨)
- 런타임 미정: Python(LangChain + FastAPI) 또는 TypeScript(LangChain.js + Next.js) 중 선택 필요
- 목표: `GenKit/` 구현과 동일한 입력(RSS 블로그 글) → 동일한 출력(LinkedIn, X, Instagram cardNews+caption, Reminder) 제공
- 비교 포인트: 체인/프롬프트 템플릿, 구조화 출력, 스트리밍, 토큰/비용, RSS 연동 편의성
