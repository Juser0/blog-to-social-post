# SpringAI 변형 (예정)

Java + Spring AI (Spring Boot) 기반 Blog → Social 변환 구현 자리.

- 상태: 미구현 (폴더만 생성됨)
- 런타임: JVM / Maven 또는 Gradle 프로젝트로, pnpm 대상이 아님
- 목표: `GenKit/` 구현과 동일한 입력(RSS 블로그 글) → 동일한 출력(LinkedIn, X, Instagram cardNews+caption, Reminder) 제공
- 비교 포인트: ChatClient/PromptTemplate 사용성, 구조화 출력, 어드바이저/메모리, 토큰/비용, RSS 연동 편의성
