# MastraAI 변형 (예정)

TypeScript + Mastra 프레임워크 기반 Blog → Social 변환 구현 자리.

- 상태: 미구현 (폴더만 생성됨)
- 런타임: Node.js / TypeScript (`@mastra/core` — Agent/Tool/Workflow)
- 목표: `GenKit/` 구현과 동일한 입력(RSS 블로그 글) → 동일한 출력(LinkedIn, X, Instagram cardNews+caption, Reminder) 제공
- 비교 포인트: 에이전트·도구 호출 오버헤드, 구조화 출력, 스트리밍, 토큰/비용, 내장 eval·Studio 활용 여부
