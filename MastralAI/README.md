# MastralAI 변형 (예정)

Blog → Social 변환 구현 자리. 폴더명은 요청 그대로 `MastralAI`로 생성함.

- 상태: 미구현 (폴더만 생성됨, 대상 확정 필요)
- 확정 필요: Mistral AI 모델 연동용인지, Mastra 프레임워크용인지 정해야 함
- 목표: `GenKit/` 구현과 동일한 입력(RSS 블로그 글) → 동일한 출력(LinkedIn, X, Instagram cardNews+caption, Reminder) 제공
- 비교 포인트: 모델 품질/비용, 구조화 출력, 스트리밍, RSS 연동 편의성
